# Website Institucional - ABCLAN

🌎 English version available below.

Este é o código-fonte do website institucional desenvolvido para a ABCLAN - Telecom & CFTV. O site é totalmente responsivo, leve, otimizado para SEO e oferece uma navegação clara e objetiva tanto em desktops quanto em dispositivos móveis.

## 🚀 Funcionalidades principais:

- Menu de navegação com submenu para produtos (versão desktop)
- Menu hambúrguer com acessibilidade e foco em UX mobile
- Formulários de Contato e Solicitação de Orçamento com:

    - Validação de campos via JavaScript
    - Envio assíncrono via AJAX (sem recarregar a página)
    - Feedback ao usuário (mensagens de sucesso/erro)
    - Integração com PHPMailer para envio de e-mails
- Seções informativas: Sobre nós, Serviços, Produtos, Contato
- Página de produtos com estrutura otimizada:

    - Listagem dos fabricantes
    - Exibição visual de cada tipo de produto
- Animações suaves com transições CSS
- Carregamento lazy de imagens (otimização de desempenho)
- Ícones sociais interativos com hover estilizado

## 🚀 Organização do CSS e Responsividade:

- CSS padronizado e organizado utilizando breakpoints personalizados:
    - De 300px até 1200px+, cobrindo toda a gama de dispositivos

## 🛠️ Tecnologias usadas:

- HTML5 e CSS3 com responsividade via media queries
- JavaScript para:

    - Interatividade geral
    - Validações
    - Envio de formulários com AJAX
- PHPMailer para envio real de e-mails
- Swiper.js para sliders/carrosséis responsivos e interativos
- Font Awesome para ícones sociais e visuais
- GitHub Pages para hospedagem gratuita do site

# Institutional Website - ABCLAN

This is the source code of the institutional website developed for ABCLAN - Telecom & CFTV. The site is fully responsive, lightweight, SEO-optimized, and offers clear and objective navigation on both desktop and mobile devices.

## 🚀 Main Features:

- Navigation menu with product submenu (desktop version)
- Hamburger menu with accessibility and UX focus on mobile
- Contact and Budget Request Forms with:

    - Field validation via JavaScript
    - Asynchronous submission via AJAX (no page reload)
    - User feedback (success/error messages)
    - Integration with PHPMailer for email sending
- Informative sections: About Us, Services, Products, Contact
- Product page with optimized structure:

    - Manufacturer listings
    - Visual display of each product type
- Smooth animations with CSS transitions
- Lazy loading of images (performance optimization)
- Interactive social media icons with styled hover effects

## 🚀 CSS Organization and Responsiveness:

- Standardized and organized CSS using custom breakpoints:
    - From 300px to 1200px+, covering a full range of devices

## 🛠️ Technologies Used:

- HTML5 and CSS3 with responsive design via media queries
- JavaScript for:

    - General interactivity
    - Form validation
    - AJAX form submission
- PHPMailer for real email sending
- Swiper.js for responsive and interactive sliders/carousels
- Font Awesome for social and visual icons
- GitHub Pages for free site hosting
